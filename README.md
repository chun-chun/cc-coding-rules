# CC Coding Rules

供大型專案選用的開發規則。各專案透過根目錄的 `AGENTS.md` 指定要讀的規則，並使用自己的 lint、型別檢查與測試指令驗證變更。

對目標專案的 agent 說：「讀取 `./cc-coding-rules/INSTALL.md`，把這套規則安裝到目前專案。」如果下載在其他位置，提供實際路徑。

- [安裝與更新](INSTALL.md)
- [共用規則](rules/core.md)
- [Python 規則](stacks/python.md)
- [專案入口範本](templates/AGENTS.md)

要繼續整理規則時，在 Codex 開啟本 repo 並建立新 session。先讀本 repo 的 [維護指示](AGENTS.md)。
